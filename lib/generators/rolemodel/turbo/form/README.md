# Form Generator

Enable dynamic form interactions in new/existing rails apps with the [turbo_form](https://github.com/OutlawAndy/turbo_form) gem.

## What you get

  - the `turbo_form` gem, set up by its `turbo_form:install` generator

Draw the `:turbo_form` route concern on each resource with a dynamic form. See the gem's README for usage.
